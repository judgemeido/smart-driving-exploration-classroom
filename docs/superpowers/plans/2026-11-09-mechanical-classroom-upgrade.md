# 01–03 机械拆解升级

本轮直接实施用户要求：保留预测—操作—证据—发现的课堂流程，把简陋功能车和传感器改成精细机械观察台。使用 teardown 的机制、几何、舞台、控制分层方法，沿用项目 Three.js，无自动接管和视频管线。

## 实施内容

1. 电驱教学台：层叠电池、母排、冷却板；定子铜绕组、转子、轴承；18/54 齿外啮合减速机构、半轴和制动盘。齿数为本教学机构设定，绝非某车型工程参数。单一输入角驱动轴、齿轮与车轮，断传动只停止输出端。
2. 感知教学台：激光发射、光学接收、探测与电路层，旋转驱动机构；摄像头镜组和毫米波阵列。结构放大观察与米制测量现场明确分开，沿用首个表面回波、遮挡和浓雾未知规则。
3. 围绕模型安排装配、剖视、分解、部件选择与局部视角，提供鼠标点选和等价 DOM 按钮。读数由模型状态计算，标签不遮挡工作部件。
4. 保留无打字、桌面一页、低配、减少动态、WebGL 备用、记录导出、原版展馆入口；不开展05/06。
5. 三个 GPT-6.1 Sol 分别完成电驱模型、感知模型和布局，主 agent 集成、科学约束测试、渲染检查与回归。

## 验收

- 手动检查总览、铜绕组剖视、齿轮分解、电池层结构、雷达光学、测距现场的当前渲染。
- 测试齿比与反向啮合、断供能/断传动、信息命令和执行区别、16m/32m回波、近处遮挡、浓雾与未命中。
- 检查1280×720、1366×768与窄屏；全量单测、构建与浏览器回归。
- 记录参考来源、教学简化范围和未做实机课堂性能验证的边界。
