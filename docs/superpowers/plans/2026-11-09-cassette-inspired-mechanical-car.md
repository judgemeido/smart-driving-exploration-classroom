# 01 机械整车重建计划

**Goal:** 以用户指定的 `D:/Codex/city/cassette-source` 为工艺参考，重建可观察机械部件的整车，并验证后上传现有 GitHub 仓库。

**Architecture:** 沿用课堂状态和 Three.js 舞台；现代纯电与混动车采用独立机械整车工厂，历史先驱与早期电动保留时代识别。机械模型按底盘、悬架、制动、电池、电机、传动、电控、座舱和车身分组，装配/剖视/分解、点选和供能状态来自同一快照。

**Reference:** 已读取参考项目 README、cassette.js、lights.js 的几何、材质和拆解组织。借鉴实体倒角、旋转体、螺钉、独立部件与弱化上下文的观察方法；不复制参考的音乐、标签、商标或成品模型。

## 实施

- [x] 补充失败测试：机械部件确实存在；轮毂/制动/悬架有独立层级；车身可逆打开；隔离不失去整体方位；状态和资源释放正确。
- [x] 建立倒角、车削环件、紧固件、线束、弹簧等共享建模工具，材质缓存和实例化控制开销。
- [x] 建造完整长轴距车架、开放轮毂、制动卡钳与盘、连杆与弹簧减振器、电池模组/铜母排、电机转子/定子、减速机构、橙色高压线束、电控板及完整座舱框架。
- [x] 用曲面车身面板、独立玻璃和立柱定义整车外形；剖视时移去车身展示机械，避免单块挤出盒状车壳。
- [x] 部件按钮、近景相机、周围弱化参照及分层位置随同模型更新；仍可键盘操作并记录证据。
- [x] 用浏览器检查真实整车/内部/分解/电机/制动/底盘画面、低配与小桌面；执行单测、构建、受影响浏览器回归。
交付步骤：验证通过后提交本轮课堂与模型改动，推送 `classroom` 远程的 `main`，最终答复报告远端提交核对结果。

模型为自主设计的功能教学构型，不声称原厂CAD、实车尺寸或完整动力学。装配外形和分解必须均有可辨认机械实体。
