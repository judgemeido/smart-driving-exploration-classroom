# 三维探索课堂：教师使用说明

适用方式为教师先讲解一段，学生每人一台电脑，在网页中独立完成对应验证。没有实体拆装、排行榜、计时竞赛或联网控班。教师通过口头讲解或投屏组织进度，网页不替教师判断学生是否真正理解。

## 每个活动的共同流程

1. 教师讲清本次问题和模型边界，请学生点击选择预测，并口头说明理由。
2. 学生改变一个条件，运行观察，阅读证据与数值，而不只看动画。
3. 保存结果，再改变一个条件重测；比较两次证据。
4. 学生选择与证据一致的发现，口头解释“哪条证据支持判断”，说明尚不知道什么。

运行失败的假设同样可以产生有意义的证据。活动完成标记不能代替教师阅读预测、前后记录和解释。模型是功能示意，不是官方车辆 CAD；开壳和剖切不是现实维修操作。

## 七个活动

| 活动 | 教师引导 | 学生网页验证 | 讨论证据 |
|---|---|---|---|
| H1 汽车进化档案 | 区分研究、示范和应用；时间先后不等于因果 | 阅读年代卡及出处，用上下移动调整顺序，选择史料推理；切换档案会定位相关结构 | 引用一张具体卡，解释技术回应了什么需要；不能只复述排序 |
| H2 能量怎样到达车轮 | 先比较三种能源路径，再说明只对纯电台架做断路 | 接通两条路径记录；只断传动重测；恢复后只断供能再测 | 电机转和车轮转是不同结果。台架忽略惯性与滑行，不代表真实车辆断电后立即停止 |
| E1 打开工作中的部件 | 区分获取信息、生成命令、输出动力和制动 | 定位部件，展开与剖切，保持连接观察，再断开一条功能连接 | 开壳只改变看法；功能改变来自供能/传动连接。让学生连接两个部件解释合作 |
| E2 让信息跑起来 | “看见”“下令”“执行”分属三环 | 运行初始故障；逐环检查两帧证据；选择诊断，只修一处，用原条件重测 | 输入不明不能判定无人；命令存在不代表执行成功。分别比较安全响应和清空后的任务进展 |
| S1 三种设备，三种线索 | 不同设备提供不同信息，还需要计算处理 | 切换摄像头、毫米波雷达、激光雷达，运行并记录 | 距离不直接包含灯色；本页没有模拟识别率或测速 |
| S2 先猜，再测一次回波 | 光去和回走两程，距离必须除以二 | 晴朗、无遮挡、0°时测16 m与32 m；再改变角度或加入遮挡 | 时间约106.7 ns和213.5 ns。角度改变射线路径与是否命中；首回波可能来自8 m遮挡物 |
| S3 天气与遮挡对照 | 不可靠信号不等于道路为空，强调一次只改一项 | 固定距离/角度，先晴朗，再轻雨/浓雾；恢复晴朗后只改遮挡 | 天气是定性样例。浓雾未知不代表任何真实设备在所有雾中都完全失效 |

## E2 建议讲解顺序

先保留默认执行链故障和正常礼让规则，观察“输入有证据、计算有命令、执行无反馈”。让学生在修复前提出诊断，并保留故障运行记录。修复执行链后重测，相同两帧应先执行停车，再执行通行。

随后可分别设置输入断点与计算断点，比较最先缺失的信息。输入断开时，两帧均为证据不确定；正常规则请求停车，但不能确认清空后通行。计算断开则连命令也不存在。错误地选择其他修复点不会接通真正故障，重测仍需依据证据重新诊断。

最后比较“始终停车”和“始终通行”规则。前者不能完成清空后的通行任务，后者不能安全礼让。不要将现实安全性简化成页面里的一个通过标签；此处仅验证给定两帧与规则。

## 保存与课堂收尾

结构活动后可打开Q1、感知活动后可打开Q2，每轮3题、每题1分。老师口头组织，学生在本机作答；提交后首次答案与分数锁定。学生主动打开讲评，另选修正，不修改首次结果。没有联网锁屏、全班统计或速度排名。

## 机械观察操作

显示操作集中在模型周围：“装配”看位置、“剖视”看内部、“分解”看层级。点击实体部件或下方同名按钮，自动进入局部观察；点击“整体”返回总览。部件选择与结构活动中的定位一致，显示开合不切断能量路径。720高度下建议先看整体，再选电机或齿轮，或按“放大观察”进入全屏；“返回课堂”或Esc退出。

01、02使用同一电驱教学机构，包含电池层结构、铜绕组、转子、齿轮、半轴、电控和制动。18齿输入与54齿输出是教学设定；断传动时输入齿轮移开，电机可转而输出停止，不应解释为真实车的维修操作。

03的“结构观察”是放大原理机，“测距现场”才是以米计的实验。先拆开看发射与接收，再切到现场改变距离、角度或遮挡。结构台固定方位，不播放完整旋转扫描；现场光传播慢放，米和纳秒读数仍来自原公式。

记录保存在当前浏览器、当前站点来源的本机空间，新活动使用独立 namespace，旧记录保留。共享电脑不要默认下一位学生看不到已有记录。按页面实际提供的导出能力留存，不能把本机保存称为“已交给老师”。遇到存储错误时保留已有原始数据，并使用可用的导出渠道；不要以清空浏览器存储作为首选修复。

教师收尾时可请学生展示一组前后记录，分别指出：保持了什么、改变了什么、证据如何变化、结论适用于什么边界。优先检查 E2 是否分清三环、S2 是否理解往返、S3 是否将未知误解为清空。

本轮没有进行儿童试讲。首次课堂应观察学生是否能独立找到控件、读懂无输出/未知、保留同条件复测并用证据解释；记录困难后再调整。源码审阅和自动测试不构成学习效果证据，也没有完成真实教室硬件性能验收。
