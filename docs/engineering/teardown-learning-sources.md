## 功能车与史料

三维车辆是用于辨认电池、电机、传动、计算、感知与制动关系的功能教学模型，不是任何品牌的官方 CAD、工程装配图或真实产品数字孪生。部件位置、尺寸、剖切和分层用于表达作用，不能据此教授真实车型维修步骤或宣称碰撞、效率和制动性能。

H1 复用 `src/chapters/history/learning-data.ts` 的年代卡与 `src/chapters/history/data.ts` 的展品、出处和图片说明；页面提供对应史料链接。年代先后只能验证排序，不能单独证明技术变化的因果。研究、示范和日常应用应分别解释，电动化与智能化可以并行。

H2 能源说明参考[美国能源部 AFDC 电动车原理](https://afdc.energy.gov/vehicles/how-do-all-electric-cars-work)。燃油、纯电和混动是能量路径对照，断路实验只模拟纯电功能台架。纯电行驶无尾气不等于全生命周期零排放；混动结构多样，不能一律视为可外接充电。

## 因果规则

- H2/E1 的能量路径为电池 → 电机 → 传动 → 车轮。供能断开时不能产生驱动力；传动断开时电机可以转动，车轮得不到该驱动力。忽略惯性、滑行、损耗与真实制动动力学。
- 分层、剖切与开壳只改变观看方式，不切断功能。信息路径与能量路径分别讲解。
- E2 固定为“行人 → 检测区域清空”两帧。输入断开产生 uncertain；计算断开不产生命令；执行断开没有执行反馈。正常礼让规则仅在证据确认清空后通行，证据不明时请求停车。
- 安全响应和任务完成分别判断：第一帧有效停车才验证安全响应；第一帧停车且第二帧通行才完成任务。始终停车不能冒充任务成功；无执行反馈不能被当作已执行制动。
- E2 修复只接通所诊断的一条链路，保留规则、电源、传动和两帧顺序后重测。模拟输出不能证明现实自动驾驶系统安全。

## 测量与天气

S1 对照摄像头的图像、颜色和纹理，毫米波雷达的距离与相对运动，激光雷达的距离与轮廓。不模拟识别率或雷达测速，距离信号不能直接提供交通灯灯色。

S2/S3 使用单束光与平面表面的米制几何：目标前表面位置可设 4–80 m，目标半宽 2 m；遮挡物在前方 8 m，半宽 2 m，只遮挡其后方目标。角度范围 −30° 至 30°。命中首个表面时，单程射线路径距离为表面前向距离除以 cos(偏转角)，往返时间 `t = 2d/c`，其中 `c = 299792458 m/s`。读数显示精度只是格式化，不代表设备精度。未命中无读数；遮挡时记录近处遮挡物回波，不能解释为后方目标距离。镜头和显示开关不改变测量。

天气是确定的定性样例：晴朗/轻雨允许几何回波，浓雾记为未知。它不是雨雾衰减方程、检出率预测或设备性能比较；真实结果还依赖浓度、材质、设备和算法。未知与无读数均不能证明道路清空。画面中的传播动画为慢放示意。
