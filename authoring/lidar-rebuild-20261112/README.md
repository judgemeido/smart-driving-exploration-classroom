# LD-016 独立建模预览

此目录是独立审核稿。没有修改主站入口、章节、模型加载器或现有资产，也没有提交、推送到 GitHub。

## 打开

在项目目录运行 `node authoring/lidar-rebuild-20261112/serve-preview.mjs`，然后访问 `http://localhost:5176/preview.html`。依赖使用项目已安装的 Three.js 与 Vite，不需要另装依赖。

访问 `http://localhost:5176/preview.html?view=board` 可直接打开外壳并单独观察测距处理板。

访问 `http://localhost:5176/preview.html?view=scan` 进入扫描画中画布局：环境测距为大画面，原模型画布嵌入右上角并保留旋转、缩放、零件点击和控制按钮。退出扫描会将同一画布放回原位；`scan-layout.css` 提供桌面与手机布局。`scan-layout-validation.json` 记录尺寸、交互与模式切换检查。

## 模型

- `LD016-reconstructed.blend`：Blender 4.5.10 LTS 编辑源文件。保留原有 Scene，新增 `LD016_Engineering` 场景；1–360 帧包含转动、拆解、复原示意。
- `LD016-engineering.glb`：米制、Y-up 的浏览器交付模型。78 个网格，12 个功能总成，约 11.8 MB。无外部贴图，无压缩解码器依赖。
- `build_lidar.py`：可重建的原始建模程序。
- `board_detail.py`：两块电路板与收发阵列的元器件、焊点、接插件、丝印和示意走线；由主建模程序加载。
- `board-detail-manifest.json`：新增 590 个独立元器件封装的统计、功能区与布局避让记录。数量仅描述教学模型，不代表真实厂商物料表或已验证电路。
- `model-manifest.json`：零件、发射/接收口、16 个仰角及拆解位移。自定义位移保留 Blender Z-up，预览统一转换成 `(x,z,-y)`。

外观采用石墨色外壳、加工金属、哑光阻焊层、FR4 板边、焊锡与镀金接点的分材质处理。`exhibit-finish.js` 与 `exhibit.css` 提供独立展台、刻字和可关闭光效；底部光环是展台灯光。光学支架采用开放框架，为接收阵列背面的电路留出空间。

## 功能与边界

支持外观、打开外壳、拆解、零件查询、单独观察、镜头聚焦、暂停、扫描、改变墙面距离、仰角选择、添加遮挡、单次发射和清空点云。手机布局和 44px 触控目标已检查；实际手机硬件帧率尚未实测。

模型是**原创通用旋转式雷达教学构型**，不是 VLP-16 的厂商拆机 CAD。16 个仰角参考开放 ROS 驱动；电路位置、导电环方案、镜筒与机械尺寸为教学设计，依据见 `research.json`。未取得官方内部制造图，不能将该模型描述为某一型号的精确内部复刻。

转子、光学阵列、测距处理板与空心轴共享转动状态；外壳、电机定子、轴承外圈和编码器读头固定。爆炸状态停转。导电环跨越固定/旋转边界，线束不随连续转动缠绕。线束接头、电磁行为和电路布线不作生产级仿真。

测距环境里的模型使用真实米制尺寸，近景只改变摄像机，不改变传感器比例。每束光从相应镜头口发出，只与首个不透明表面相交，并检查返回接收口的路径是否被遮挡。无回波则不生成点。时间为 `(发射口至击中点 + 击中点至接收口) / 299792458`；等效距离为总光路的一半。近景短线是方向示意，传播脉冲为慢放示意。窗口默认允许工作波段红外通过。

点云为理想几何交点，未模拟材料反射率、透射、多回波、噪声和光学效率；不构成激光器安全或测距性能验证。原模型、渲染及预览代码为本任务原创；Three.js、Vite 继续适用项目原有依赖许可。

## 验证

`preview-validation.json` 记录浏览器功能检查、测距和遮挡检查，以及 390 / 720 / 1024px 的布局检查。`validate-preview.mjs` 可在本机已安装的 Edge 与测试运行库下复查。最终主要总成的爆炸位置做轴向包围盒检查，不能据此推导生产级装配精度或全路径碰撞验证。
